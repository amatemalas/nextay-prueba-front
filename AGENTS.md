# AGENTS.md — nextay-prueba-front

## Stack

Quasar v2 SPA with Vue 3 (Composition API), Vite, and file-based routing. No TypeScript — JS only with `jsconfig.json`. No tests.

## Commands

```bash
pnpm install          # postinstall runs `quasar prepare --silent`, generates .quasar/
quasar dev            # dev server, opens browser automatically
quasar build          # production build
pnpm run lint         # prettier --write + eslint --fix (auto-fixes in place)
pnpm run lint:check   # same but read-only (no writes)
```

There is no separate typecheck or test command.

## Lint & Format

- Prettier: no semicolons, single quotes, 100 char print width (`.prettierrc.json`).
- ESLint flat config at `eslint.config.js`. Vue rule `multi-word-component-names` is disabled.
- `pnpm run lint` runs Prettier then ESLint in a single step. Run it before committing.

## Routing (file-based, non-obvious)

Routes are auto-generated from `src/pages/` via `vue-router/auto-routes` (`quasar.config.js:41`).

- `src/pages/index.vue` is the **layout shell** (contains `q-layout` + `q-page-container`). It is NOT the home page content.
- `src/pages/index/(index).vue` is the actual home page rendered inside that layout.
- `src/pages/[...path].vue` is the catch-all 404 route.
- Nested routes use subdirectories under `src/pages/`.
- Router mode is **hash** (URLs look like `/#/path`).

When adding or modifying pages, create `.vue` files in `src/pages/` — do NOT manually register routes in the router file.

## Project Structure

```
src/
  App.vue              # minimal, just <router-view />
  pages/               # file-based routes (see above)
  components/          # reusable Vue components
  css/
    app.scss            # global styles (currently empty)
    quasar.variables.scss  # SCSS variable overrides
  boot/                 # Quasar boot files (currently empty)
  assets/               # static assets
  router/index.js       # router setup, auto-imports routes from pages/
```

## Gotchas

- `.quasar/` is generated by `quasar prepare` and gitignored. It provides type hints (`jsconfig.json` extends `.quasar/tsconfig.json`).
- The `lint` script runs Prettier across ALL matched files (js, vue, css, scss, html, md, json), not just src/. Check `.gitignore` for exclusions.
- ESLint vite-plugin-checker is **disabled in dev** (`server: false` in `quasar.config.js:65`), so lint errors only surface during `quasar build` or `pnpm run lint:check`.
- Node engine requirement: `>= 26 || ^24 || ^22.12`.
